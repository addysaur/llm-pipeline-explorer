Field Notes — How to read this

What you're actually seeing

1 — TOKEN ≠ WORD

A token can be a word, part of a word (##isation), or punctuation. Models never see raw letters — only token IDs.

2 — EMBEDDING = COORDINATES

Each ID is looked up in a table to get a vector. Training moves vectors so meaning becomes geometry.

3 — 3D IS A SHADOW

You can't plot 16-D (or 4096-D) directly. PCA squashes it to 3D — useful, but some neighbours get distorted. That's normal.

4 — NEXT: ATTENTION

After embeddings, position is added and attention lets tokens look at each other. That step isn't plotted here — this tape ends at the embedding room.
